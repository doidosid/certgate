# ADR-003: 인증서 유효기간

- **상태**: 확정
- **결정일**: 2026-08-13

## 결정

| 인증서 | 기본 유효기간 |
|---|---:|
| Root CA | 10년 |
| Intermediate CA | 3년 |
| Device Certificate | 30일 |

## 선택 이유

- Root CA는 최상위 Trust Anchor이므로 가장 길게 유지한다.
- Intermediate CA는 실제 발급에 사용되므로 Root CA보다 짧게 운영한다.
- Device Certificate는 탈취·오용 시 노출 기간을 줄이고 만료·갱신 시나리오를 보여주기 위해 30일로 제한한다.

## 구현 규칙

- 인증서는 발급한 상위 CA의 남은 유효기간을 넘을 수 없다.
- 기본값은 설정으로 관리해 테스트에서 짧은 만료 시간을 사용할 수 있게 한다.
- 제출용 MVP는 자동 갱신보다 만료 감지와 접속 차단을 우선 구현한다.
