# 관리 콘솔 UI 설계

## 1. 설계 원칙

- 제출용 MVP는 핵심 보안 흐름을 빠르게 파악할 수 있는 관리 콘솔을 목표로 한다.
- 별도의 Alert 관리 화면과 상태 관리 기능은 만들지 않는다.
- Critical Security Event는 접속 중인 사용자에게 실시간 토스트로 알리고, 원본 Event는 보안 이벤트 화면에서 보존·조회한다.
- 화면 표기는 한국어를 기본으로 하되 인증서·프로토콜의 표준 용어는 영문을 함께 사용한다.

## 2. 화면 구성

관리 콘솔은 다음 5개 화면으로 구성한다.

1. 대시보드
2. 디바이스
3. 인증서 요청
4. 인증서
5. 보안 이벤트

## 3. 대시보드

- 상단 요약 카드: 활성 디바이스, 유효 인증서, 승인 대기 CSR, Critical Event
- 최근 24시간 요청 허용·차단 추이
- Gateway, Management API, PostgreSQL 상태
- Gateway SQLite Outbox 대기 건수와 가장 오래된 미전송 시간
- 최근 Critical Security Event 패널
- 패널 항목 클릭 시 보안 이벤트 상세로 이동

## 4. 디바이스

- 검색·필터: 이름, Device ID, 상태, Role
- 목록: 이름, Device ID, Role, 상태, 인증서 상태, 만료일, 마지막 접속
- 상세: 기본 정보, 인증서, 적용 정책, 최근 보안 이벤트
- 관리 기능: 등록, 활성화·비활성화, 인증서 조회·폐기
- 이력 보존을 위해 물리 삭제는 제공하지 않는다.

## 5. 인증서 요청

- 목록: 요청 ID, 디바이스, SAN URI, 키 알고리즘, 요청일, 상태
- 상태: 승인 대기, 발급 완료, 거절
- 상세: CSR Subject, SAN, 공개키 정보, CSR 지문
- 관리 기능: 승인, 사유를 포함한 거절
- 승인 전 등록된 Device ID와 CSR의 SAN URI 일치 여부를 검증한다.
- Device 개인키는 서버와 관리 화면에 저장하거나 표시하지 않는다.

## 6. 인증서

- 목록: Serial Number, 디바이스, 상태, 발급일, 만료일, 발급 CA
- 상태: 유효, 만료 임박, 만료, 폐기
- 검색·필터: 상태, 디바이스, 만료 기간
- 상세: Subject, SAN URI, SHA-256 지문, 유효기간, 폐기 정보
- 관리 기능: 공개 인증서 다운로드, 사유를 포함한 인증서 폐기
- 만료 7일 전부터 만료 임박으로 표시한다.
- 재발급은 기존 인증서를 복사하지 않고 새 CSR 요청으로 처리한다.

## 7. 보안 이벤트

- 목록: 발생 시각, 디바이스, 요청 경로, 결과, 사유, 접속 IP, 응답 시간
- 결과: 허용, 차단, 오류
- 검색·필터: 기간, 디바이스, 결과, 이벤트 코드, 심각도
- 상세: 인증서 Serial, HTTP Method, Trace ID, 정책 판단 결과
- 동일 Trace ID로 관련 요청을 추적한다.
- 보안 기록은 수정·삭제할 수 없다.
- 개인키, 인증서 원문, 전체 Telemetry Payload는 저장·표시하지 않는다.

## 8. 실시간 Critical 알림

- Spring Boot가 `/api/v1/security-events/stream`에서 SSE를 제공한다.
- React는 로그인 후 SSE 연결을 유지한다.
- Critical Event 수신 시 화면 오른쪽 위에 카카오톡 알림 형태의 토스트를 표시한다.
- 토스트에는 알림 유형, 디바이스, 발생 시각을 표시한다.
- Critical 토스트는 자동으로 사라지지 않으며 사용자가 직접 닫는다.
- 토스트 클릭 시 원인이 된 Security Event 상세로 이동한다.
- 토스트를 닫아도 원본 Security Event는 삭제되지 않는다.
- SSE 연결이 끊긴 동안의 이벤트는 재접속 후 최근 Critical Event API 조회로 보완한다.

## 9. Critical 판정 기준

- 폐기된 인증서로 접속
- 동일 IP에서 유효하지 않은 인증서가 1분에 5회 이상 발생
- CA 인증서 서명 실패
- Gateway 미전송 Event가 100건 이상 누적
- 가장 오래된 미전송 Event가 1분 이상 지연

일반 경고는 대시보드와 보안 이벤트 화면에 표시하고 실시간 토스트는 Critical 등급에만 사용한다.
